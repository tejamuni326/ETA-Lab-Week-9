## Setup
1. Install Python 3.9 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   `python -m pip install -r requirements.txt`
4. Run a lab, for example:
   `python -m streamlit run lab1/app.py`

Each lab folder has its own README. For labs requiring external services (API, AI provider, PostgreSQL), configure credentials locally and never commit secrets.
